# Envtester snap

> [!NOTE]
> This is an experimental and unstable version of the core application used in
> the [snapcraft env-injector extension][doc-env-inject].
> Check the upstream version on:
> - https://github.com/canonical/snappy-env

This snap is a PoC for the `env-exporter` program.

`env-exporter` is a program that can dynamically load snap options into environment variables

Build it:
```bash
snapcraft -v
```
